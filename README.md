# Chocolatey.Docs.Cake.Recipe

The need for this repository, and the set of opinionated build scripts is no longer required.
The web assets for Chocolatey are now built using Astro, rather than Statiq, and as such, we
can go ahead and archive this repository.

This repository contains a set of opinionated Cake Scripts which are used to build some of the documentations sites for Chocolatey, for example:

- https://blog.chocolatey.org/
- https://docs.chocolatey.org/en-us/
- https://chocolatey.org/
- https://chocolateyfest.com/
- https://boxstarter.org/
